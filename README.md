# NextPlay 🎮

Your personal gaming sidekick — track new releases, manage your backlog, and find the perfect game to play next.

**Live Demo:** [https://nextplay-eta.vercel.app](https://nextplay-eta.vercel.app)

## Features

- **Release Radar** — See new games launching today, this week, and this month
- **My Shelf** — Organize your games (Playing, Want, Beaten, Dropped)
- **Next Play Quiz** — Answer a few quick questions and get personalized recommendations
- Clean, modern, mobile-friendly interface
- Powered by the free RAWG game database

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- RAWG API
